This entry follows the "trace of a stranger" angle: a small, specific object left behind in a shared place becomes a window into the life of someone who is not there. The object is ordinary and concrete, the place is one everyone has stood in, and the surprise lands at the very end, when a worn detail quietly reveals more about its owner than a name ever could. No moral is attached; the object simply tells its own story.

## Run it

```sh
node main.ts
```

This writes the one-sentence entry to `/output/entry.txt`.
